The first public release of Agentic Grove: a calm desktop cockpit for your AI agents, meant to sit
open on a spare screen all day.

![The grove in use](https://raw.githubusercontent.com/Adiezc/agentic-grove/v0.1.0/assets/screenshots/grove-demo.webp)

## Install

Needs a Mac with Apple Silicon (M1 or later) and macOS 13 Ventura or newer.

1. Download `Agentic-Grove-0.1.0-arm64.dmg` below.
2. Open it and drag **Agentic Grove** onto **Applications**.
3. Open the app. macOS refuses the first time, because it is not signed with a paid Apple developer
   certificate.
4. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway** beside Agentic
   Grove, and confirm. From then on it opens normally.

On first launch, PM walks you through the grove and one **Get ready** button sets up
Claude Code or Codex if you need it.

## What it does

- **Each project is a stone.** It lights while an agent works there and turns amber when an agent
  is waiting for you. Git worktrees stand beside their repository as twin stones.
- **Tell PM what needs doing.** PM, the project manager on the tree, plans the job, hands each part
  to the right agent (Researcher, Builder, or agents you add), checks the work and reports back.
  It runs in Terminal, in that project, as your own Claude Code or Codex, on your own plan.
- **Or send one agent yourself**, from the tree or by naming it in the console.
- **Save the jobs you repeat** as one-click tasks, and leave notes for the next time work starts on
  a project.
- **See how much you have left:** five-hour and weekly headroom for Claude and ChatGPT, each figure
  marked official, counted or unknown.
- **Ask about your own week** ("what did I do yesterday?"), answered from the records on your Mac.
- **Calm all day:** it draws less when nothing is happening and almost nothing when hidden.

## Privacy

No telemetry, ever. Everything it reads stays on your Mac. The only request it makes by itself is a
daily check of this page for a newer version, which you can turn off in Settings.

## Known limits

- Mac only for now. A Windows port is the most wanted contribution; see
  [CONTRIBUTING.md](https://github.com/Adiezc/agentic-grove/blob/main/CONTRIBUTING.md).
- The Grove starts work; it does not run it. To stop or answer an agent, use its Terminal window.
- Claude's official limits are read only when you press Check now in Settings.
- Not signed or notarised, so the Open Anyway step above is needed once per version.
